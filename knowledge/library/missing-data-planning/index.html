Missing data requires a planned response

Describe what is missing, why the chosen method is plausible and how conclusions change under alternative assumptions.

Direct answer

No single percentage of missing values determines the correct method. The response depends on the analysis, missingness process, observed predictors of missingness, model compatibility and sensitivity of the decision.

Plan before choosing a method

  1. Map missingness. Report variables, cases, patterns, timing and reasons where known.
  2. Protect the estimand. State the target quantity and which missing values threaten its interpretation.
  3. Make assumptions explicit. Explain why complete-case analysis, maximum likelihood, multiple imputation or another method is defensible.
  4. Align models. Include variables and relationships needed to make the imputation and analysis models compatible.
  5. Test sensitivity. Examine whether conclusions depend on plausible departures from the main missingness assumption.

Deletion is an analysis choice

Complete-case analysis can change the target population and reduce precision. It can be valid under particular conditions, but it should not be treated as a neutral default. Likewise, imputation does not recover unknown truth; it propagates uncertainty under a stated model.

Worked use case

Income is more often missing among self-employed respondents. A complete-case model may change the composition of the sample. Include observed predictors related to missingness, document the imputation model and compare the substantive conclusion with a complete-case and sensitivity analysis.

Evidence boundary

Missing-at-random assumptions cannot generally be proven from observed data alone. Diagnostics can reveal patterns and model problems, but sensitivity analysis is needed when departures could alter the decision.
